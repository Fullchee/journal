Privacy Policy

Last updated 9 November 2026

This is a private, single-user app. No one else can sign in.

What it reads from Google

  • Calendar events on calendars the user grants access to.
  • Free/busy times on calendars shared with the user.

How it uses that data

To plan the day and prepare weekly summaries for the user.

Google data is never sold, shared, used for ads or used to train AI models.

Where data is stored

  • The Google sign-in token is kept as an encrypted secret.
  • Calendar data is read when needed and not stored, apart from events the app creates.

Phone contacts (Android)

When the user picks a person from their phone contacts, the app reads that contact's name, birthday and photo on the device. It reads no other contacts and never changes them.

  • The app stores only the name, the birthday and the contact's id.
  • The photo is read from the phone each time and never uploaded or stored.
  • Contacts permission can be revoked at any time in Android settings.

Google API Services User Data Policy

This app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Revoke access at any time at myaccount.google.com/connections.
